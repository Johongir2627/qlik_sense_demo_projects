Movie Dataset Analysis Project

1. Project Overview
This project is focused on analyzing a movie dataset containing key information about popular films, 
including their financial performance, production details, and award achievements. 
The dataset enables exploratory data analysis to understand trends in movie budgets, 
box office success, genres, and Oscar performance.
The project can be used for data analysis, data visualization, statistical analysis, or 
machine learning tasks such as predicting box office revenue or Oscar wins.

2. Objectives
The main objectives of this project are:
    To analyze the relationship between movie budgets and box office revenue
    To explore how genre, director, and country influence movie success
    To examine the impact of Oscar nominations and wins on financial performance
    To provide structured data suitable for business intelligence dashboards or predictive models
