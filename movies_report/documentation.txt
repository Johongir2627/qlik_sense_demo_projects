Movie Dataset Analysis Project

1. Project Overview
This project is focused on analyzing a movie dataset containing key information about popular films, 
including their financial performance, production details, and award achievements. 
The dataset enables exploratory data analysis to understand trends in movie budgets, 
box office success, genres, and Oscar performance.
The project can be used for data analysis, data visualization, statistical analysis, or 
machine learning tasks such as predicting box office revenue or Oscar wins.

2. Objectives
The main objectives of this project are:
    To analyze the relationship between movie budgets and box office revenue
    To explore how genre, director, and country influence movie success
    To examine the impact of Oscar nominations and wins on financial performance
    To provide structured data suitable for business intelligence dashboards or predictive models

3. Dataset Description
The dataset contains information about movies released between different years, 
covering financial, artistic, and award-related attributes.

Dataset Fields
| Column Name      | Description                        |
| ---------------- | ---------------------------------- |
| **ID**           | Unique identifier for each movie   |
| **Title**        | Name of the movie                  |
| **Release Date** | Official movie release date        |
| **Run Time**     | Duration of the movie in minutes   |
| **Genre**        | Primary genre of the movie         |
| **Director**     | Movie director                     |
| **Country**      | Country of production              |
| **Certificate**  | Age rating / content certificate   |
| **Budget**       | Production budget (USD)            |
| **Box Office**   | Worldwide box office revenue (USD) |
| **Nominations**  | Number of Oscar nominations        |
| **Oscar Wins**   | Number of Oscars won               |

4. Sample Records
Example movies included in the dataset:
Jurassic Park (1993) – High box office success with multiple Oscar wins
Titanic (1998) – One of the highest-grossing movies with record-breaking Oscar wins
Spider-Man (2002) – Strong commercial performance with fewer awards
